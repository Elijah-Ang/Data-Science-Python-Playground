# 6 September 2026 release

This release brings together the end-to-end audit remediation and the subsequent user-directed UI corrections.

- Replace the three large workspace artwork buttons with a compact pixel navigation switcher, with visible HOME/DATA/ML labels, accessible destination names, active state and inset keyboard focus.
- Keep the compact top-right landing tour; remove added landing CTAs, appearance selectors, duplicate navigation captions and notebook-management/conclusion controls.
- Data opens with an empty notebook. Older Data drafts remain stored but are not automatically loaded or overwritten. Machine Learning retains its existing draft behavior. Dataset details and preview remain visible.
- Remove the ML Inspector holdout paragraph; show the title and three-bar symbol consistently at phone widths.
- Correct native light/dark status-area backgrounds and improve text contrast.
- Apply all 26 ML workflow audit remediations: learner-editable execution, evidence invalidation, clear baseline/tuning/final distinctions, corrected preprocessing, clustering and PCA workflows, and aligned teaching copy.
- Repair Data execution/reset/serialization, cancellation, navigation, accessibility, charts, scoped caching, production asset manifests and build identity.

Validation before release includes JavaScript/state/teaching and structural route checks (254 configurations), focused Chromium/WebKit UI checks, and pinned Pyodide browser journeys. Earlier full runtime runs covered all 254 route configurations. Physical iPhone checks are recorded locally by exact installed build; full VoiceOver, memory-pressure and offline certification are not implied.

The requested UI revisions supersede earlier audit recommendations for automatic Data restoration, manual notebook export, conclusions, larger route controls and extra appearance controls. Tests have been updated to the current product contract.
