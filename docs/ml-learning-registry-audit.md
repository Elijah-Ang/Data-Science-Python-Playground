## Independent routes and intentional joins

- Regression and Classification each require shared supervised foundations; neither requires the other branch.
- Shared Neural Networks reaches N01/N02/N05/N-R1 from W-K1. Neural regression requires R03; neural classification requires C06. Each has its own checkpoint.
- Discovery reaches W03 directly from F-K1 and then U01/U02; W01/W02 and the supervised workflow checkpoint are unnecessary. PCA uses U01/U02 but no clustering-model checkpoint.
- M01 intentionally joins regression, classification, both neural tasks, clustering and PCA for broad task/model-family choice. This capstone is optional to any individual model route.
- Prerequisite links are advisory and every route is freely accessible. Core means essential within the relevant pathway/model family.
- W-K1 uses LinearRegression with a justified defaults decision. Tree depth stays in R09/R10 and C14. C14 teaches its own generic tree mechanics.
- W06 retrieves W02 for its dummy-reference pipeline exercise. This supervised dependency does not reach W03.
