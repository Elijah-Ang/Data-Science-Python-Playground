# Downloadable review preview

This archive contains the self-contained Data Foundations and Machine Learning
review preview from commit `77a0ffb832f6f2480b7a3b8149b5cabf08ceece4`.
It is provided here so downloading does not depend on Codex cloud-file access.

Download `curriculum-preview.zip`, unzip it, and open
`curriculum-preview/OPEN-IN-BROWSER.html` in Safari or Chrome.
No local server is required. Running Python requires internet access for the
pinned runtime packages. The archive includes instructions.

The HTML rendering and navigation were checked without a workspace HTTP server.
Direct file navigation is blocked by this environment's managed browser policy;
opening the downloaded file in Safari on macOS has not been independently tested.

No curriculum source changes, merge, or production deployment accompany this file.
