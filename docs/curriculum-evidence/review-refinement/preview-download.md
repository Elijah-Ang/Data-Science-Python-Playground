# Downloadable review preview

This archive contains the self-contained Data Foundations and Machine Learning
review preview from source commit `59305ecef4d705b53fce57aa26bafbd2f89d46bd`.
Download `curriculum-preview.zip`, unzip it in Finder, then open
`curriculum-preview/OPEN-IN-BROWSER.html` with Safari or Chrome.
Both curricula are available through the buttons at the top.

No server is required. Running Python needs internet access for the pinned
runtime packages. The archive includes instructions. It avoids Codex cloud-file
retrieval and workspace-local server URLs.

The bundle passed isolated browser rendering, navigation and Data/ML Python
checks. Direct Safari file navigation on a physical Mac is not independently
tested. See [the stage visual report](../../curriculum-stage-visual-review.md)
and [validation evidence](../stage-visuals/validation.json).
