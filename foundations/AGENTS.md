# Foundations product policy

The user explicitly prohibits saved learning, saved drafts, resume systems, completion records, progress bars/indicators, and progress tracking in any way, shape, or form until they explicitly request these in a future task. Do not infer authorization from general learning-experience improvements.

Keep learner code only in the active editor; navigation/reload starts from the exercise starter. Run, Check answer, Stop/restart, and Reset code remain available. Shared theme preferences are independent of learning state. This policy also applies to Data Foundations HTML, tests, and integrations outside this directory.
