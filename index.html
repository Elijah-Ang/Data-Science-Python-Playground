What happens inside the playground?

A question, a table, an answer you can check

1. Inspect
and prepare

  • Explore real datasets: Seoul Bike, Palmer Penguins and Wine Quality.
  • Understand rows, columns and units.
  • Check missing values and cleaning choices.

2. Run the Python
yourself

  • Edit a cell and run Python in your browser.
  • Read the resulting table or figure.
  • Practise on small tables, then apply the idea to bigger datasets.

3. Judge
the evidence

  • Turn summaries and charts into statistical questions.
  • Compare models with a simple baseline.
  • Check assumptions and draw honest conclusions.
