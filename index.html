A QUESTION, A TABLE, AN ANSWER YOU CAN CHECK

What happens inside the playground?

Suppose bike hire looks busier on warm afternoons. Start by checking the dates, missing values and units. Compare demand by hour, then draw a chart before deciding what the pattern supports. A visible association is a question to investigate, not proof that temperature caused the change.

Inspect and prepare

Work with bundled datasets such as Seoul Bike, Palmer Penguins and Wine Quality. See the actual rows and column meanings, keep a safe copy, and make each cleaning choice explicit.

Run the Python yourself

Edit a cell, run it in your browser, and read the resulting table or figure. Small practice tables help you learn one idea at a time; the open workspace lets you apply it to larger datasets.

Judge the evidence

Move from summaries and labelled charts to statistical questions and model comparisons. Check assumptions, compare with a simple baseline, and reserve the final test for an honest evaluation.
