A five-minutes tour

LIVE UI MAPDATA PLAYGROUND

Choose a dataset or upload a CSV. The playground keeps the original data safe while you experiment.

01 · choose a dataset

Start with a question, not a blank page.

Use the Data Playground selector for a curated dataset, or upload a CSV. In Machine Learning, the first strip also asks for a feature scenario, model, and cross-validation plan.

Open the data selector →
02 · read the inspector

Know what you are holding.

Before writing code, read the dataset card, row and column counts, data types, and preview. Data Playground says ORIGINAL KEPT; ML shows selected features and a TEST SET SEALED holdout.

03 · follow the route

Let the workflow give you momentum.

Data moves from Inspect to Wrangle to Visualise. Its suggested cards are runnable starting points, and the notebook remains editable. ML’s suggested workflow is longer: choose/frame, split and seal the final test, explore training data, prepare, build the model, baseline cross-validation, tune or keep defaults, diagnose, then run the final test.

04 · run, then read

Every run should answer something.

Press Run, or run the suggested route. Outputs stay in the lab as tables, charts, scalars, console text, and downloadable results. In ML, metrics and diagnostics are shown without opening the sealed holdout early.

05 · use the right guide

Practice after the tour.

Data Playground’s Challenges turn the same datasets and techniques into optional prompts. Machine Learning’s Workflow reference explains the modeling path. Multiple valid Python solutions are welcome.

See Data Challenges →
06 · choose your finish line

Explore a pattern—or prove a model.

Choose Data Playground when the question is about rows, transformations, comparisons, or visual evidence. Choose Machine Learning when the question is about features, a model, cross-validation, and a defensible metric.

Open Data Playground →
07 · switch labs when the question changes

Start broad, then choose the sharper tool.

Begin in the general Data Playground for wrangling and visualisation. When you are ready to frame features, models, cross-validation, and metrics, use the same navigation to switch to the Machine Learning Playground.

Switch to Machine Learning →
