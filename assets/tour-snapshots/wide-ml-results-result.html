Terms and model notes
CONCEPT
FOLDA fold is one part of the training data temporarily held out for validation. With 5-fold CV, each round trains on 4 parts and validates on 1; each part gets one turn.
WHY CVCross-validation gives several training-only validation results instead of relying on one lucky or unlucky split. The final test set is not involved in any of these rounds.
FOLD SETUPBefore standard folds are made, shuffle=True mixes the row order so folds are not based on the dataset's original order. Stratified folds try to keep class proportions similar in each fold.
METRIC MEANING
Macro F1 ↑measures classification quality for each class and then gives every class equal weight. Higher is better, which makes it useful when smaller classes should matter too.

# Each fold fits on its training rows and checks different validation rows.
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

    pipeline, X_train, y_train, cv=cv, scoring="f1_macro", return_train_score=True,

    "fold":np.arange(1, len(cv_results["test_score"]) + 1),
    "train_macro_f1":cv_results["train_score"],
    "validation_macro_f1":cv_results["test_score"],

# 8 · Tune the model inside the same training folds
from sklearn.model_selection import GridSearchCV

parameter_grid = {
    'model__C': [0.1, 1.0, 10.0]
