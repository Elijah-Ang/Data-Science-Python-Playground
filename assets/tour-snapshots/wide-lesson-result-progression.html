Understand the idea

A DataFrame is a table. A dictionary supplies the column names and lists of values; items at the same position become one row.

A small example

Names ["Ada", "Ben"] and ages [4, 7] become two rows: Ada · 4, then Ben · 7.

Follow the code

Apply the idea to the supplied table. Read from top to bottom; the final line displays the result.

import pandas as pd

data = {
    "candy": ["Gummy Bear", "Choco Pop", "Mint Bite", "Berry Loop"],
    "price": [1.2, 2.1, 1.5, 2.8],
}

df = pd.DataFrame(data)
df

What each part does

1import pandas as pd
load pandas and give it the short name pd
2data =
save our dictionary under the name data
3{ }
a dictionary pairs column names with their values
4[ ]
a list holds the values of one column in row order
5"price"
quotes make text; numbers such as 1.2 need no quotes
6pd.DataFrame(data)
turn that dictionary into a table
7df =
store the table under the name df
Read the symbols

Quoted text is a string; [ ] encloses a list. = assigns a value to a name. import pandas as pd gives pandas the short name pd.
