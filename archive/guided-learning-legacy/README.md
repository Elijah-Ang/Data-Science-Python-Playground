# Guided Learning Archive

This folder is a preserved snapshot of the former landing page and Guided Learning experience.

- `index.html` is the archived two-path gateway.
- `learning.html` is the archived space-route learning hub.
- `learning-app.js`, `learning.css`, and `data/` are kept together so the snapshot remains inspectable.

The archived pages link forward to the active root `playground.html` and `ml.html` routes. Shared datasets stay in the root `data/` directory; the archived curriculum uses paths relative to this folder.

The active product home page lives at the project root. This archive is intentionally outside the active navigation and is retained for reference while Guided Learning is paused.
