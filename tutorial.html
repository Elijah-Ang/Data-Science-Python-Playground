01 / Data Playground

Meet the table first.

Choose a bundled dataset. Check its size, column meanings and preview in the inspector. Each row is an observation; each column describes one part of it. Use Suggested Route for a starting point, or open Challenges for more questions.

Explore data →

02 / Notebook & output

Change. Run. Read.

Choose a route task to add and run its cell, or edit Python and press Run. Cells share the current Python session. On wide screens, output sits beside the notebook; on narrow screens, the notebook comes first, then output. Each pane scrolls independently.

Open the notebook →

03 / Statistics Playground

Measure uncertainty.

Open STATS. Choose a dataset, then use Study setup to describe your question and variables. Set the confidence level and follow the suggested route. Read estimates, intervals and assumptions together: a small p-value does not tell you an effect is large or useful.

Investigate statistics →

04 / Machine Learning

Test predictions fairly.

Open ML. Choose a dataset and target, select features and a model, then follow the modelling route. Use Workflow for guidance. Train to fit, validate to compare choices, and keep the final test set untouched until your choices are settled.

Try machine learning →

06 / Data Foundations practice

Less help as you go.

Follow starts with guidance. Change applies the idea to a different table. Transfer asks you to work independently. Run executes your code; Check answer checks the task; Reset code restores the starter. Navigating or reloading starts fresh. Learning progress is not saved.

Try the first practice →

Before you leave

Python runs on your device. Opening an interactive lesson or workspace for the first time may take a moment to load packages. Reading this tour and the lesson library does not start Python.

Use Stop / restart Python if a calculation gets stuck; restarting clears Python variables. Keep a copy of work you want to retain. See Help for workspace storage and export behaviour, and Privacy for hosting and advertising details.
