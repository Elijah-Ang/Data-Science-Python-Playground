Get unstuck quickly

Most work stays on your device. If something stops responding, use the steps below before resetting the data workspace.

Python is still loading

  1. Wait for the runtime status to say ready.
  2. Check your connection on the website’s first visit.
  3. If loading fails, reconnect and reopen the page or app.

A cell failed

  1. Read the error in the output panel.
  2. Undo the latest edit or use the reference workflow.
  3. Reset only when you want to restore the untouched dataset.

Data and export

Choose one of the bundled datasets to begin. Importing your own CSV is deferred beyond version 1. Use CSV or chart export to save your result; in the native app, the system share sheet offers Files and other destinations.

Offline use

The native app packages the Python runtime and bundled datasets for offline work. The website caches its interface, but a first Python run may still need a connection to fetch the browser runtime.

Your data and session

Data Playground starts with an empty notebook each time it opens; copy code you want to keep before leaving. Machine Learning code drafts and bundled dataset text save automatically on this device for each setup. Python variables and results are temporary and reset when you reopen the workspace. CSV and chart exports are created only when you choose them through the browser or native share sheet. There is no account, cloud synchronisation, analytics or project-operated storage for analysis work.
