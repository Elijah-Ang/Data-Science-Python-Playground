Learn by working with real data

Data Science Python Playground is a local-first teaching lab created by Elijah Ang. It turns data questions into editable Python workflows, visible evidence, and machine-learning decisions you can inspect step by step.

What it does

Explore bundled datasets, edit and run Python cells, build charts, compare models, and protect the final test set while learning from realistic data.

How your work is handled

Code drafts and bundled dataset text save automatically on this device for each setup. Python variables and results are temporary and reset when you reopen the workspace. CSV and chart exports are created only when you choose them through the browser or native share sheet. There is no account, cloud synchronisation, analytics or project-operated storage for analysis work.

Web and app

The GitHub Pages site remains the computer experience. The iPhone and iPad app packages the same tested web source inside a native shell.
