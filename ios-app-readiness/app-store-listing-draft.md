## Draft description

Data Playground is an interactive learning lab for exploring data, writing Python, building visualisations, and understanding machine-learning evidence.

Choose a real dataset, inspect its structure, ask a question, and work through a live notebook. Edit Python cells, run them, read tables and charts, and keep the original data safe while you experiment.

The Machine Learning Playground guides you through feature and target selection, train/test splitting, preprocessing, cross-validation, model fitting, diagnostics, and a final holdout evaluation. Practice mode helps you make decisions before revealing reference code.

The first release is designed for learners who want a clear, hands-on path from data questions to evidence-based conclusions.
