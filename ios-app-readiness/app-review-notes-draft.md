# App Review Notes — Draft

Data Science Playground is a free, no-account educational data-analysis app. It runs Python locally inside the app using a bundled WebAssembly/Pyodide runtime. It does not require a login or backend service.

## Suggested review path

1. Launch the app and choose **Data Playground**.
2. Select a bundled dataset and run an editable Python cell.
3. Import a CSV with the file picker; the file remains on the device and in the active session.
4. Export a CSV or chart and choose a destination from the iOS Share Sheet.
5. Open **Machine Learning**, select a compatible dataset/model route, and run the guided workflow.
6. Turn off network access after a successful clean launch and repeat a bundled-data journey to verify the packaged runtime.

The app preserves a one-use final holdout in supervised teaching routes. Clustering and PCA routes are clearly separated from supervised evaluation. External dataset-source links open through the system-backed browser surface.
