Machine Learning — Learn / Refresh

Start with a question, learn the Python and build a model. Enable JavaScript to choose a deck and practise with interactive Python exercises.

How the lessons work

Learn what a model result can actually support

Each route connects an idea to editable code and asks you to interpret the evidence it produces. Begin with features, targets and a careful train/test split. Learn a supervised workflow before choosing regression or classification; then explore networks, clustering, PCA and comparison. The small practice tables let you check one decision at a time.

Compare fairly

A model earns its place by improving on a simple reference under the same validation setup. Fit preprocessing on training folds only, compare candidates on matching folds and keep the final test rows aside until selection is finished.

Read the right evidence

For regression, read errors in the target’s original units. For classification, inspect a confusion table as well as an aggregate score such as macro F1: one number can hide which class the model misses.

Respect the limits

Cluster numbers are assigned group names, not known labels. PCA shows retained variation, not predictive accuracy. A result on a small teaching table is practice in reasoning, not a claim that a model will generalise to every new setting.

Why the baseline matters

If a delivery-time model has a mean absolute error of 7 minutes and a simple training-mean predictor makes 6-minute errors on the same validation folds, the more complex model has not earned an improvement claim. Try changing the features or model, then check the comparison again.
